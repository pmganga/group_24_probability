## Commit convention

Format: `type: short description` (lowercase, present tense)

| Type | Use for |
|---|---|
| feat | new functionality (e.g. `feat: add E-step responsibility calculation`) |
| fix | bug fixes (e.g. `fix: correct variance denominator in M-step`) |
| docs | README, notebook text, explanations |
| data | adding or updating datasets |
| refactor | restructuring without behaviour change |
| chore | setup, config, dependencies |

Each member commits their own work from their own GitHub account.
